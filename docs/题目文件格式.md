# 题目文件格式（JSON 导入导出）

题库“从 JSON 导入”和“导出”用的文件格式。代码在 `src/questions/format.ts`。

```json
{
  "schemaVersion": 1,
  "kind": "questions",
  "questions": [
    {
      "uid": "可选，同一道题的唯一标识",
      "type": "单选",
      "stem": "控制回路中常见的文字符号 TWJ 表示什么？",
      "options": ["合闸位置继电器", "跳闸位置继电器", "防跳继电器"],
      "answer": "B",
      "explanation": "解析，答完后显示",
      "tags": ["控制回路"],
      "reviewStatus": "草稿",
      "source": "手工录入"
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `uid` | 可选。导入时按 uid 判断是不是题库里已有的同一道题；不写就当新题。导出的文件都带 uid。 |
| `type` | 单选 / 多选 / 判断 / 排序（也可以写 single / multi / judge / order） |
| `stem` | 题干，必填 |
| `options` | 选项数组，2～26 个；判断题不写 |
| `answer` | 单选写字母 `"B"`；多选写 `["A","C"]` 或 `"AC"`；判断写 `"对"` / `"错"`；排序写正确顺序的字母 `["C","A","B"]`，不写时选项本身就是正确顺序 |
| `explanation` | 解析，可选 |
| `tags` | 标签数组，可选 |
| `reviewStatus` | 草稿 / 已审核，不写按草稿。只有已审核的题进入复习（设置里可以改成草稿也参与） |
| `source` | 手工录入 / AI 生成 / 来自原理笔记 / 内置示例 / 导入，不写按“导入” |

文件也可以直接是一个题目数组 `[ {...}, {...} ]`。

## 导入规则

- 先预览：新题、和题库完全相同、uid 相同但内容不同、格式有错，各几道。格式有错的题跳过，并列出原因。
- uid 相同但内容不同的题，勾选“用文件里的内容更新”才会覆盖。
- 覆盖时按固定规则处理：题干、选项、答案、解析或审核状态有变化，内容版本号 +1，这道题的复习进度重置；只有标签变化不重置。

## 复习规则（SM-2）

- 每天先复习到期的题，再学新题；数量受设置里“每日新题上限”“每日复习上限”限制。
- 答错：按“没记住”记分，明天再复习，并在本轮最后再练一次（这一次不计入排期）。
- 答对：自己选“有点难 / 还行 / 很简单”（SM-2 评分 3 / 4 / 5）。第 1 次间隔 1 天，第 2 次 6 天，之后按上次间隔 × 难度因子。
- 复习记录和题目分表存放（`review_records`、`review_log`），旧内容版本的记录保留为历史，不参与排期。删除题目时复习记录一并删除。
