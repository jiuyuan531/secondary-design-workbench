# 二次设计工作台

变电站二次设计用的本地桌面程序，包含两个模块：

- **模块 A：二次回路学习**（交互式回路演示、题库与间隔重复复习、读图找错、原理笔记）
- **模块 B：项目看板**（项目、卷册、任务、待确认问题、收资/提资记录）

完整需求与里程碑见 [AGENTS.md](AGENTS.md)。所有数据只保存在本机。

## 获取程序

两种方式任选：

1. **直接下载**：在 GitHub 仓库的 Actions 页面打开最新一次“Windows 打包与自检”，下载 `erci-workbench-windows` 压缩包，里面有免安装版和安装版 exe。
2. **本地打包**：本机装好 Node.js 22 或更新版本，双击 `build.bat`，完成后到 `release` 文件夹取 exe。

打包好的 exe 不需要安装 Node.js 就能运行。

> 国内网络下载 Electron 很慢时，可以在运行 build.bat 前先执行
> `set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`

## M0 验收方法

在一台**没装 Node.js** 的 Windows 电脑上：

1. 双击 `erci-workbench-版本号-portable.exe` 启动。
2. 首页“数据库状态”里能看到数据库文件位置和表结构版本。
3. 点“运行读写自检”，显示“✓ 读写正常”。关掉程序再打开，再点一次，累计次数会加 1（说明数据确实存进了文件）。
4. 打开“设置”，修改“仿真步数上限”为 300 并保存，重启后仍是 300；填 5 会提示“不能小于 10”。

## M1 验收方法

1. “项目看板 → 新建项目”，录入一个真实项目，再在项目详情页里加卷册、任务、待确认问题。
2. 新建问题时选择“信息性质”，添加来源并选择“来源类型”；勾选“来源之间有矛盾”后填两个来源，分别写下两边说法。
3. “卷册看板”里拖动卡片（或用卡片上的下拉框）改变卷册状态。
4. 首页能看到 14 天内到期的卷册和任务、各项目未解决问题数。
5. “设置 → 备份数据库”，然后删掉项目，再“从备份恢复”，项目和下面的全部内容都回来。

分类选项（项目类型、卷册状态、信息性质等）在 `src/board/enums.ts`，字段和说明在 `src/board/model.ts`。

## M2b 验收方法

“回路演示”里选“防跳回路”：
1. 场景选“带防跳：合于故障”，连续点“下一步”，断路器合上后被跳开，不再重合，状态显示“回路稳定”。
2. 场景选“去掉防跳：跳跃现象”，连续点“下一步”，状态显示“检测到振荡”，并给出循环区间。
3. 选“断路器控制回路”，点图上蓝色的 SA_close 接点，再点“单步”逐步观察合闸过程。
4. 选“控制回路断线告警”，在右侧勾选一个故障，点“运行到稳定”，断线信号灯亮。

5. 点“⛶ 放大查看”（或双击图的空白处），回路图铺满窗口；滚轮缩放、按住空白处拖动，Esc 退出。
6. 场景选“去掉防跳：跳跃现象”，点“▶ 自动播放”：按场景步骤自动执行，“运行到稳定”一个 tick 一个 tick 慢放，能看到断路器反复合上、跳开；检测到振荡后再多放一圈后停下。没有可播放的变化时会提示先操作接点。

内置的 3 个回路都是**草稿**，接法、高低阻取值和讲解需要沈审核。

### 新增回路

“回路演示”左侧回路列表下面：

- **新建回路**：从一个最小的空白模板开始；**复制当前回路**：以选中的回路为底稿另存一份；**编辑当前回路**：改已有回路。
- 编辑器左边是回路文件（JSON），右边实时显示回路图。格式不对时下方用中文列出哪里错了，改正之前不能保存。
- 元件和节点的位置不用手写坐标：在右边图上直接拖动（自动对齐到 10 的整数倍），双击元件切换横放 / 竖放。
- 覆盖已有文件前，旧内容会自动存到回路文件夹下的“历史版本”子目录。
- “格式速查”列出常用写法，“完整格式说明”打开 [docs/回路数据格式.md](docs/回路数据格式.md)。

自己写的回路请保持 `"reviewStatus": "草稿"`，确认无误后再改成 `"已审核"`。
